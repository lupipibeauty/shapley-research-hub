# 04 C2 跨层统计语义审计

## 实际 SQL 结果

DuckDB 上执行了 `COUNT(record_id)`、`COUNT(DISTINCT entity_id)`、`GROUP BY`、`GROUPING SETS`、父子层次、空组和 NULL 检查。

- 数据库 A：city_1、city_2 的 DISTINCT 均为 1，同一实体在两城重复；省级 DISTINCT 为 1。
- 数据库 B：两个城市的 DISTINCT 仍均为 1，但实体不同；省级 DISTINCT 为 2。
- 空城市通过维表 LEFT JOIN 保留，行计数和 DISTINCT 都为 0。
- NULL_CASE 有一条物理行，`COUNT(record_id)=1`，`COUNT(DISTINCT entity_id)=0`。
- CROSS_A/CROSS_B 的地区边际和行业边际相同，但地区×行业单元不同。

这证明仅保存叶级或边际数值不足以恢复父级去重和交叉统计；至少要保留实体身份以及实体—层次/类别的关联来源。它是来源语义和表示需求，不是新的困难性定理。
