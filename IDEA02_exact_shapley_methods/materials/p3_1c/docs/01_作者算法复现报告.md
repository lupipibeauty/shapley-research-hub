## Abramovich 2025 R1

官方归档 SHA256 为 `7e28ba907c2d1af830d49b89d8647f4ecd4d14dc6817ed73cabc791d2c31ef3c`。除三个运行时 `.pyc` 缓存外，归档内文件与本地快照逐文件一致；README、两个 LExaShap 核心文件和论文 PDF 的哈希已单独保存。ZIP 不含 `.git`，所以 commit 标为 `UNVERIFIED_ZIP_HAS_NO_GIT_METADATA`，没有伪造 commit。

官方 `DNFCircuit` 实际暴露的是每个变量的按联盟大小梯度向量，而不是直接的单个标量。根据 `ShapleyEngine.py` 的根梯度和叶概率向量，本地适配器采用：

`Shapley_i = dot(gradient_i, probability_i) × 2^n / n!`。

此系数没有使用 P3 oracle 拟合。它先在单变量、AND3、OR3、共享变量重叠 DNF、dummy 扩展以及 README DNF 上独立验证，全部误差为 0。dummy 玩家在官方活动变量集外显式补 0；Shapley 的 dummy 扩展不改变其他玩家的支付。

因此 R1 状态为 `R1_REPRODUCED`。限定语义是：作者 Boolean 核心未经修改；从梯度到标量的包装器是本地适配代码，不称为作者接口。

## 论文边界

- Theorem 3.6：给定 d-tree，所有变量的 Banzhaf 为 `O(|T|)`，Shapley 为 `O(|T|·|vars(T)|²)`。该界不含 SQL 来源提取、DNF 构造和 d-tree 编译。
- Proposition 4.1：按 semimodule 可能值和联盟大小模型计数表达聚合 Shapley。
- Proposition 4.2：给定 MIN/MAX semimodule d-tree，对相关值与联盟大小的计数可多项式计算。

本轮公开代码实测使用 Boolean LExaShap。论文的 MIN/MAX 理论结果不能自动当作仓库中已有完整 MIN Shapley 命令行接口。
