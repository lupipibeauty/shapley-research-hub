# H5-V2-JOINT-STATE：V2 数学结构与联合状态充分性

日期：2026-10-31  
对象：冻结 D1-P，12 个记录玩家、7 个地理节点、35 个报表坐标、P/E/J/M 四个统计族  
目标：证明一个不依赖已知 Shapley 支付的充分统计状态，并明确该证明不等于多项式时间保证。

## 1. 冻结价值函数

四个统计族得分记为 `f_P(S), f_E(S), f_J(S), f_M(S)`，冻结族权重均为 `1/4`。

```text
F_A(S) = [f_P(S)+f_E(S)+f_J(S)+f_M(S)] / 4
F_G(S) = [f_P(S) f_E(S) f_J(S) f_M(S)]^(1/4)
V2(S)  = R[(1-λ)F_A(S)+λ F_G(S)]
R=1000, λ=1/2
```

若任一族得分为 0，冻结规则令 `F_G(S)=0`。对全部 4096 个联盟的有理数核验给出：

```text
V1(S) = R F_A(S)
```

因此由 Shapley 线性性：

```text
φ_i(V2) = (1-λ)φ_i(V1) + Rλφ_i(F_G).
```

本轮的新计算对象是 `F_G`，V1 部分复用 AB-N3-L/AB-N4-DP 已独立核验的精确支付。

## 2. 联合状态

对每个叶节点 `l in {A1,A2,B1,B2}` 定义四计数：

```text
z_l(S) = (n_l, e_l, j_l, m_l)
```

- `n_l`：叶内记录数；
- `e_l`：叶内 E2 记录数；
- `j_l`：叶内 OptionalAttribute 存在记录数；
- `m_l`：叶内 OptionalAttribute 存在且为 manufacturing 的记录数。

全局状态为四个叶状态的串联：

```text
Z(S) = (z_A1, z_A2, z_B1, z_B2) in N^16.
```

每条原始记录的增量由其叶节点、E1/E2、Optional 存在性和 manufacturing/service 标签直接生成。状态设计过程不读取 4096 联盟价值或已知 Shapley 支付。

## 3. 充分性证明

### 3.1 所有 7 节点的基础统计都由 Z 决定

叶节点的四计数已在 `Z`中。父节点 A/B 是对其两个叶的逐分量求和，COUNTRY 是对四个叶的逐分量求和。因此任意节点的 `(n,e,j,m)` 都是 `Z` 的确定函数。

### 3.2 所有 35 个坐标得分都由 Z 决定

计数坐标只使用 `n/e/j` 与满表参考值。两类比例坐标均为分段线性评分：

```text
E-share(n,e) = n/F - |eF-nC|/F^2
M-share(j,m) = j/Fj - |mFj-jCm|/Fj^2
```

当分母计数为 0 时，冻结规则给分 0，与上述化简式一致。满表参考 `F,C,Fj,Cm` 是固定外生常数。故 35 个坐标、四个族得分、`F_A`、`F_G` 和 V2 都是 `Z` 的确定函数。

### 3.3 Shapley 权重也可由 Z 得到

每条玩家记录恰好使某一叶的 `n_l` 增加 1，因此联盟大小是

```text
|S| = n_A1+n_A2+n_B1+n_B2.
```

对 12 玩家游戏，焦点玩家的大小 `k` 前驱联盟每个的 Shapley 权重为

```text
1 / [12 * C(11,k)].
```

因此 `Z`不仅决定边际价值，也决定边际项所需的联盟大小。

### 3.4 结论

对任意焦点记录 `i`，只要 DP 保存每个可达状态 `Z`的前驱联盟重数，就能精确计算

```text
sum_Z multiplicity(Z) / [12*C(11,|Z|)] * [F_G(Z+Δ_i)-F_G(Z)].
```

这证明了 `Z` 对冻结 V2 的充分性。全部 4096 联盟之后的验证只用于检查证明和代码，不用于构造状态。

## 4. B2 与 B3

### B2：充分状态 DP

对每个焦点玩家，从空状态出发，对其他 11 条记录依次执行“不加入/加入增量”转移，并合并相同 `Z`的联盟重数。

### B3：叶因子生成函数/变量消去

因为每条记录只属于一个叶，先在每个叶内建立局部系数表：

```text
G_l(x) = product_{i in leaf l, i != focal} [1 + x^(Δ_i)].
```

再将四个叶因子卷积。系数是到达联合状态的联盟数。这是经典生成函数/变量消去视角的可执行实现，不是新算法声明。

## 5. 充分性不等于高效性

本例的 16 维计数盒子上界是 34,992,000，但受 12 个二进制玩家限制，独立子集上界为 4096；实际可达联合状态为 3840。B2/B3 的某些焦点前沿达到 2048，即全部 `2^11` 个前驱子集都映射到不同状态。

因此：

- 已证明：存在不需要先读取联盟价值表的精确状态算法；
- 未证明：该算法对一般玩家数或一般联合统计族是多项式的；
- 未观察到：在冻结 D1-P 上达到足以超过 B0 的状态压缩。

## 6. 两个实际反例

1. `S={p1}` 与 `S={p2}` 的 P 叶计数状态相同，但 P/E 几何评分分别为约 0.05556 和 0.12423。因此 P 状态不足以计算两族几何游戏。
2. `S={p7,p9}` 与 `S={p5,p11}` 当前四族得分向量相同，但同样加入 `p6` 后 E 族得分分别为 `5/32` 和 `7/48`。因此“当前四族标量得分”虽能决定当前 `F_G`，却不是对记录增量封闭的转移状态。
