# V1/V2 价值函数性质与数值审计规范 v4.0

状态：`DESIGNED / NOT_RUN`。本文件给出数学推导、精确数值规则和待执行的 4096 联盟检查；不包含运行结果。

## 1. 冻结前提

本审计只适用于 `config/value_spec_v3_2.yaml` 的冻结定义：

- 收入池 `R=1000`；
- 35 个坐标及其权重在运行前固定；
- 所有有效坐标和统计族权重非负；
- 坐标是否有效只由满联盟参考值决定，不能随当前联盟动态删减或重新归一化；
- 当前分母为 0 时比例得分为 0；
- 满联盟参考分母为 0 时，该坐标对所有联盟均无定义，应在运行前一次性剔除，并按配置在固定范围内重新归一化。

任何算法若改变这些规则，必须使用新的 `value_version`，不能与冻结 V1/V2 计算数值误差。

## 2. 计数覆盖率的单调性

对一个有效计数坐标，记满联盟计数为 `C>0`，联盟计数为 `c(S)`：

\[
q_{count}(S)=\frac{c(S)}{C}.
\]

若 `S⊆T`，逻辑记录包只增加而不删除，且查询计数单位保持不变，则 `c(S)≤c(T)`，所以

\[
q_{count}(S)≤q_{count}(T).
\]

该坐标使用整数和有理数精确计算，不需要浮点容差。若 `C=0`，则所有联盟的该计数都为 0；坐标按满联盟规则固定剔除。

## 3. 比例得分的单调性

记满联盟分母和目标分子为 `D>0`、`A`，当前联盟为 `d`、`a`，其中 `0≤a≤A`、`0≤d-a≤D-A`。冻结比例得分为：

\[
q_{ratio}(a,d)=
\begin{cases}
0,&d=0,\\
\dfrac{d}{D}\left(1-\left|\dfrac{a}{d}-\dfrac{A}{D}\right|\right),&d>0.
\end{cases}
\]

当 `d>0` 时可化为：

\[
q_{ratio}(a,d)=\frac{d}{D}-\frac{|aD-Ad|}{D^2}.
\]

加入一个计入分母的目标记录后，`(a,d)→(a+1,d+1)`，令 `x=aD-Ad`：

\[
\Delta_1=\frac{1}{D}-\frac{|x+(D-A)|-|x|}{D^2}
\ge \frac{1}{D}-\frac{D-A}{D^2}
=\frac{A}{D^2}\ge0.
\]

加入一个计入分母的非目标记录后，`(a,d)→(a,d+1)`：

\[
\Delta_0=\frac{1}{D}-\frac{|x-A|-|x|}{D^2}
\ge \frac{1}{D}-\frac{A}{D^2}
=\frac{D-A}{D^2}\ge0.
\]

从 `d=0` 到第一条有效记录时，得分由 0 变为非负值。未计入该坐标分母的记录使得分不变。因此，在固定参考值和固定计数单位下，该比例得分单调不减。

上述推导不覆盖多对多 JOIN 造成的非预期重复、联盟相关的坐标剔除、动态权重归一化或加入记录后删除既有输出的查询。D1-X 中出现这些结构时必须重新验证前提。

## 4. V1 的单调性结论

V1 是有效计数覆盖率和比例得分的固定非负加权和。由第 2、3 节，冻结 D1-P 上理论预期为：

\[
S\subseteq T\Rightarrow V1(S)\le V1(T).
\]

这是一项待程序核验的不变量，不是已经完成的实验结果。若 4096 联盟检查发现负边际，优先检查：

1. 坐标权重是否随联盟变化；
2. `NULL` 是否被不同实现转换成不同值；
3. JOIN 是否改变逻辑计数单位；
4. 满联盟参考分子/分母是否固定；
5. 报表坐标顺序是否错位。

## 5. V2 的单调性结论

记统计族得分 `F_f(S)∈[0,1]`，权重 `θ_f≥0`，且正权重按配置归一化。算术项为：

\[
A(S)=\sum_f\theta_fF_f(S),
\]

几何项为：

\[
G(S)=\prod_{f:\theta_f>0}F_f(S)^{\theta_f}.
\]

如果每个 `F_f` 单调不减，则 `A` 单调不减；幂函数和乘积在非负正交域上对每个自变量单调不减，因此 `G` 也单调不减。对 `0≤λ≤1`：

\[
V2(S)=R[(1-\lambda)A(S)+\lambda G(S)]
\]

仍单调不减。任一正权重族得分为 0 时，几何项按配置精确记为 0；这与从正数取对数的计算分支分开处理。`λ=0` 必须走有理数分支并与 V1 精确相等。

## 6. 统一数值规则

### 6.1 精确有理数层

以下对象使用整数或 `Fraction` 等有理数精确表示：

- 四个内部计数；
- 两个比例的分子/分母；
- V0、V-count、V1；
- Shapley 子集权重；
- V2 的 `λ=0` 分支；
- `v(∅)`、`v(N)` 和预算平衡。

不得先转成显示小数再比较。精确层的相等判断容差为 0。

### 6.2 非线性高精度层

V2 几何项使用任意精度十进制或等价高精度库：

- 基准精度：80 位十进制有效数字；
- 边际绝对值小于 `10^-30 × max(1,R)` 时，以 120 位精度重算；
- 两种精度下符号不稳定则记为 `NUMERICALLY_UNRESOLVED`，不得强行判单调或非单调；
- 内部单调性零容差：`epsilon_property = 10^-30 × max(1,R)`；
- 跨算法结果容差：`epsilon_algorithm = 10^-9 × max(1,R)`；
- 报告实际最大绝对误差和相对误差，不能只报告“通过”。

### 6.3 NULL 与零参考值

- SQL 层无分母比例始终保留 `NULL`；
- 价值层当前分母为 0 且满联盟分母大于 0时，坐标得分为精确 0；
- 满联盟分母为 0 时，坐标在运行前固定剔除并按配置一次性重新归一化；
- 满联盟计数参考值为 0 时同样固定剔除；
- 不允许把 `NULL`、0 和“坐标不存在”合并成一个未标记状态。
