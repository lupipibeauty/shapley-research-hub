# AB-J2：多 distinct key、JOIN 扇出与 HAVING 门槛控制实验设计

状态：**DESIGN ONLY / 未执行**  
冻结日期：2026-10-31  
边界：独立控制游戏，不修改 D1-P；本轮不生成 64 联盟结果或 Shapley 支付。

## 1. 玩家与基础关系

玩家是六条基础记录，每条记录仅绑定一个变量：

| 玩家 | 关系 | join_key | distinct_key |
|---|---|---|---|
| p1 | JLeft | a | K1 |
| p2 | JLeft | a | K1 |
| p3 | JLeft | b | K2 |
| p4 | JRight | a | — |
| p5 | JRight | a | — |
| p6 | JRight | b | — |

`a` 形成 2×2 JOIN 扇出，`b` 形成 1×1 JOIN。满联盟的五个 grounding 为：

- K1：`p1p4`、`p1p5`、`p2p4`、`p2p5`；
- K2：`p3p6`。

## 2. 查询与来源表达

共同 grounding CTE：

```sql
WITH Grounding AS (
  SELECT l.record_id AS left_player,
         r.record_id AS right_player,
         l.distinct_key
  FROM JLeft l
  JOIN JRight r USING (join_key)
)
```

### J2-Q1：bag COUNT(*)

```sql
SELECT COUNT(*) FROM Grounding;
```

来源表达是五个合取 grounding 的线性和，满联盟期望值为 5。该查询用于确认 JOIN 扇出必须保留 bag multiplicity。

### J2-Q2：COUNT(DISTINCT distinct_key)

```sql
SELECT COUNT(DISTINCT distinct_key) FROM Grounding;
```

每个 key 内先按 OR 合并 grounding，再跨 key 求和：

```text
OR(p1p4, p1p5, p2p4, p2p5) + OR(p3p6)
```

满联盟期望值为 2。该表示是数学等价归约；不能据此声称官方发布接口原生支持 SQL `COUNT DISTINCT`。

### J2-Q3：每个 key 的 HAVING 门槛

```sql
SELECT COUNT(*)
FROM (
  SELECT distinct_key
  FROM Grounding
  GROUP BY distinct_key
  HAVING COUNT(*) >= 2
) passed_keys;
```

K1 达到两个 grounding 的最小正 DNF 子句为：

```text
OR(p1p4p5, p2p4p5, p1p2p4, p1p2p5)
```

K2 只有一个可能 grounding，阈值 2 下恒为假。满联盟期望值为 1。这里检验的是“先按 key 聚合、再做阈值、最后计数”的语义，不得把 grounding 总数阈值与 key 级 HAVING 混为一谈。

## 3. 正确性关卡

1. 在独立临时数据库中建表，不写入 D1-P。
2. 每条基础记录在所有 grounding 中保持同一个玩家变量。
3. 来源表达必须从实际 SQL grounding 生成，手写表达只作预期对照。
4. 全部 64 个联盟逐值比较直接 SQL 与来源表达。
5. 满联盟值依次为 Q1=5、Q2=2、Q3=1；空联盟均为 0。
6. Q1 保留重复 grounding；Q2 对同一 key 的 grounding 做 OR；Q3 对每个 key 独立判阈值。
7. 对三个查询分别计算 64 联盟精确 Shapley，并与官方可接受输入的结果逐玩家核对。
8. 分开记录 SQL grounding、distinct 归并、HAVING DNF 编译/最小化、d-tree 编译、Shapley 求解和端到端成本。
9. 若失败，分别登记数学表示、SQL-to-lineage 编译接口、表达规模或官方求解器限制。

## 4. 预期支持边界与资源风险

- Q1 延续 AB-J1 的直接 COUNT 线性和路径，但扇出从两个 grounding 扩大为五个。
- Q2 延续“按 distinct key 手工 OR 后可求解”的路径；通用 SQL 编译器仍是未验证能力。
- Q3 的阈值 Boolean 函数存在正 DNF，但最小子句数可能随扇出快速增长；本设计不据固定 2×2 案例推断一般规模。
