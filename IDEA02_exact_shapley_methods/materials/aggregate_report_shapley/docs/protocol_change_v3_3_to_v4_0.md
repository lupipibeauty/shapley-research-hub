# v3.3 到 v4.0 实验设计变更记录

状态：协议修订完成，所有新增检查和实验均未运行。

| 项目 | v3.3 | v4.0 |
|---|---|---|
| 首轮阶段 | T/R/A 双轨表述 | 按用户要求收敛为 S0、S1、R0、R1 四个优先阶段 |
| 价值性质 | 要求记录负边际，但推导较简略 | 新增 V1 计数/比例单调性推导、V2 算术/几何单调性推导和 4096 联盟检查 |
| 数值规则 | 有理数与浮点容差原则性区分 | 新增精确有理数层、80/120 位高精度层、NULL/零参考值和统一容差配置 |
| 官方复现 | Abramovich/Luo 为首批对象 | R0 独立成阶段，记录原目标复现、独立 oracle 和论文数值可比性 |
| 同目标适配 | A1–A7 通用阶梯 | R1 分设 AB 与 LU 路线，并要求逐联盟来源表达/效用等价核验 |
| 组合实验 | 通用方法 A/B/C | S2 固定完整 35 坐标参照，重点测试层次×指标、指标×JOIN、层次×复杂来源 |
| 复杂结构 | 作为后续结构因素 | 新增独立 D1-X：交叉分组、多对多、重复连接路径、跨来源依赖 |
| 状态模型 | 适用性与复现两列 | 拆为 `theory_status/code_status/same_game_status` 三列 |
| 当前执行 | 全部未运行 | 仍全部未运行；本次不执行附件中的 clone/build 命令 |

保持不变：

- 冻结 D1-P、SQL 语义、OwnerMap、35 坐标和值函数；
- 主玩家为逻辑记录包；
- owner 游戏和层次分配不进入第一轮；
- 历史结果不覆盖；
- 只有同玩家、同联盟数据库、同报表和同价值函数才能比较算法误差；
- 所有实验说明和结果使用中文。
