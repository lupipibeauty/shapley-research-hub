## 2. 统一目录与不可变原件

执行时为每个外部算法建立独立目录，至少包含：

```text
external/<algorithm>/source/       # 固定提交，只读保存
external/<algorithm>/environment/  # 锁文件和环境说明
external/<algorithm>/original/     # 原论文输入、命令、原始输出
external/<algorithm>/adapter/      # D1-P 适配器；不得改写 source
outputs/v3_3/reproduction/<algorithm>/<run_id>/
```

若许可证或仓库策略不允许复制源码，只记录 URL、提交哈希和本地检出说明。适配代码与原始代码分离；任何补丁都保存为补丁文件并说明必要性。

## 3. AR：Abramovich 官方实现

已核验的公开事实：官方仓库要求 Python 3.11 或更高版本，包含 DNF Boolean 公式上的 LExaBan/LExaShap、MAX 的 LExaBan 及既有 ExaBan/ExaShap/AdaBan；SUM/COUNT 输入为“DNF 与系数”的列表，MAX/MIN 输入为“合取集合与系数”的列表；README 指向 ProvSQL 作为来源表达获取工具。

执行顺序：

1. 冻结仓库提交、Python 版本和依赖；
2. 先运行仓库提供的最小示例和实验 notebook；
3. 对小 DNF 用本项目独立精确枚举核验每个玩家的 Shapley；
4. 分别记录 DNF 构造、来源获取、分解树/算法预处理和 Shapley 求值成本；
5. 构造 D1-P R1/AB-1 单 COUNT 的 DNF/系数输入；
6. 依次进入 AB-2–AB-6，每次只增加一个结构因素；
7. 对不能表达的价值函数记录 `INTERFACE_MISMATCH`，对不满足算法定义的结构记录具体 `ASSUMPTION_MISMATCH`。

不能把“ProvSQL 可生成来源”直接写成“本项目所有 SQL 均可无损转换”。每个查询必须实际生成或由人工可核验的来源表达支持。

## 4. LU：Luo 官方实现

已核验的公开事实：官方仓库面向 VLDB 2022 论文，README 给出 Ubuntu 20.04、Rust、`cargo build --release`、数据分配脚本和 owner Shapley 运行入口。

执行顺序：

1. 冻结提交、Rust 工具链、Cargo.lock 和 OS 环境；
2. 获取官方数据并保存校验值；若数据不可用，明确记录；
3. 按 README 运行数据分配脚本和至少一个官方方案；
4. 在可枚举小样本上用独立 owner 联盟真值核验；
5. 记录数据准备、最小合成发现、SC/SL/IUSV 选择、Shapley 计算和总成本；
6. 在 D1-P 中先构造满足独立非负可加输出效用的投影；
7. 分别测试“记录即 owner”和“多个记录同 owner”两个游戏，绝不把记录支付汇总当作 owner 联盟真值；
8. V2 或其他交互目标若违反独立效用假设，记录为具体 `ASSUMPTION_MISMATCH`，不要求软件强行运行。

## 6. D1-P 适配器合同

每个适配器输入必须包含：

- `record_id -> source_variable`；
- 同一逻辑记录包中多元组的绑定规则；
- 固定外生表与联盟激活表；
- 查询或来源表达；
- 报表坐标到算法输出的映射；
- 整表价值函数或等价分解证明。

适配器输出必须包含：

- 算法接收的原生输入；
- 可逆映射或无法逆映射的说明；
- 每个玩家的结果；
- 与精确真值的误差；
- 构造时间、求值时间、内存和中间结构大小；
- 失败分类。

## 7. 性能实验设计

三种方法 A/B/C 使用相同硬件、线程和输入版本：

| 维度 | 固定项 | 单独变化项 | 主要观测量 |
|---|---|---|---|
| 指标宽度 | 玩家、层级、JOIN | `m` | 重复来源编译与共享收益 |
| 层级 | 玩家、指标、JOIN | `L`/节点数 | 祖先展开和输出状态大小 |
| 玩家 | 报表模板、层级 | `p` | 精确/近似 Shapley 增长 |
| 数据量 | 玩家映射、查询 | `n` | 扫描、JOIN 与来源生成 |
| 连接 | 玩家、指标 | JOIN 数/基数 | 来源表达膨胀和身份保持 |
| owner 包 | 记录总数、查询 | 每 owner 记录数 | 变量绑定与 owner 游戏成本 |

每个条件先进行正确性检查，再计时。若精确方法达到资源上限，保留最后一个完成点与第一个失败点，不外推未测规模。
