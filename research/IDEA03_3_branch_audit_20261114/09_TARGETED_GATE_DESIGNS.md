# 两个定向准入 gate

本轮不执行 gate。以下仅冻结准入设计；总数严格限制为两个。

## GATE-A：异构聚合联合数值状态

对应分支：3-2。

固定项：

- 同一个 N≤16 物理事实玩家集合；
- 同一 SQL、相同 NULL/零分母规则；
- 预注册 7 节点、35 坐标中的最小非退化子集：至少含 COUNT DISTINCT、SUM、比例；
- 同一个可加保真度 G；
- 全联盟 oracle 只用于验收，不作为结构算法输入。

比较：现有精确布尔分量分解 vs 直接联合 aggregate-state DP。二者必须输出同一玩家 Shapley。

记录：分量数、唯一来源节点、状态数、frontier、消息元素数、构造/求解/materialization 时间、RSS、精确误差。

通过条件：至少两个递增结构规模中，联合状态在扣除输出写出后，内部状态或运算量相对分解路径出现可解释的结构性减少，且误差为 0 或在冻结精度容差内。

否定条件：状态笛卡尔积不小于分解路径；收益只来自共享 SQL 扫描；或更改了 Q/G。

## GATE-B：共享 DAG 的多根 coalition-size backward

对应分支：3-3，并为 3-4 非可加 multi-G 提供机制证据。

固定项：

- 同一 provenance/arithmetic DAG；
- 预先冻结 \(M\) 个根，不事后选择公共节点最多的根；
- 同一 N、同一精确消息语义；
- 单根作者算法作为基线。

比较：逐根单独 backward vs 共享前向+批量精确反向。输出均为显式 \(M\times N\) 矩阵。

记录：DAG 公共节点比例、每根可达节点、root-node 稀疏矩阵、前向和反向消息元素数、运算数、构造/求解/materialization 时间、RSS、逐项误差。

通过条件：扣除 \(MN\) materialization 后，批量反向的内部消息/运算随公共子图而低于逐根和，并在至少两个共享比例下呈一致趋势。

否定条件：仅共享 circuit 构造；只获得常数级编程优化；或把结果改成压缩表示后与显式矩阵基线比较。

## 执行顺序

先 GATE-B：它直接决定 3-1 的公共子 DAG 能否进入归因层。再 GATE-A：若异构状态本身爆炸，可避免在错误状态设计上扩展多根实现。任何 gate 失败都保留否定结果，不追加随机种子或扩大数据来挽救结论。
