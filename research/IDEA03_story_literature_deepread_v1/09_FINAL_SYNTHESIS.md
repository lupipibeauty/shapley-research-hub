# IDEA-03 研究故事竞争文献精读：综合结论

## 1. 十张卡之间新显现的共同理论问题

共同问题不是 Shapley 公式，而是三种转换的一致性：

1. 报表如何转为买方任务价值 `G`；
2. 供给与控制关系如何转为玩家集合 `N`；
3. `G∘Q` 的结构如何转为可复用的精确计算表示。

现有文献已分别成熟地处理这些层的局部对象，但本轮没有发现一篇原文同时以“多源完整层次统计报表—物理记录—外生固定收入—任务价值—精确来源求解”为统一模型。这个结论只表示当前覆盖矩阵存在交叉缺口，不等于创新已成立。

## 2. 哪些故事主要是成熟理论的应用

- A1 的“价值依赖用途”本身已由信息价值和 Data Shapley 文献充分支持。
- C1 的“组值等于记录值求和”分支已被 FGSV 强覆盖；owner 直接作为玩家是另一游戏。
- C2 的 endogenous/exogenous tuple 是标准 provenance 建模；是否分钱主要需制度依据。
- A3 若只引入乘积、min 或阈值，容易被 MC-net/Harsanyi/Boolean 分解覆盖。
- D2 若只做 ML 数据点添加/删除的近似更新，与 Xia/Yang 工作高度接近。

这些卡不是应删除，而是不能把上述成熟部分作为主创新。

## 3. 有意义的现实冲突

- 可恢复层次小计不应凭重复权重增加“信息价值”，但报表展示便利又可能有真实用途价值。
- 记录、事实包和 owner 的可控制单位不同，事后汇总与直接 owner game 会产生不同支付。
- 多买方任务确实会改变贡献，但固定收入与任务效用必须分开。
- 少量版本更新可能改变全体边际，但 SQL 结果局部性不足以证明 Shapley 局部性。

## 4. 最值得下一轮正式审计的 3–5 个组合

### 组合 R1：表示冗余不变性与真实互补

- 通俗例子：城市小计可推出省级总量，但省级去重企业数和跨行业比例不能简单恢复；买方又必须联合使用企业与就业指标。
- 一句话问题：如何让记录分配对纯复制展示不敏感、对真实不可恢复联合信息敏感？
- 理论问题：逐联盟信息等价；冗余不变与互补敏感的兼容条件；对应充分状态/quotient 是否降低精确计算。
- 玩家/价值：物理记录；`V(S)=G(Y(S))`，`G` 由任务定义。
- 最强竞争：Blackwell、Comparisons of Signals、aggregate provenance、MC-nets、LExaShap。
- 未决核心：多信号理论能否直接把层次报表压缩为最小充分表示。
- 最大风险：退化为预处理去重后套标准 Shapley。

### 组合 R2：精确多任务报表归因的离线—在线复用

- 通俗例子：同一报表被不同买方反复使用，每位买方有不同但结构化的决策评分。
- 一句话问题：固定 SQL 来源时，多个 `G_k` 的精确 all-player Shapley 能共享什么中间量？
- 理论问题：任务无关充分状态；可支持的 `G` 类；离线成本与在线任务数界限。
- 玩家/价值：同一物理记录集合；`V_k=G_k∘Y`。
- 最强竞争：D-Shap、LMFAO/F-IVM、LExaShap、共享电路/AD。
- 未决核心：精确而非插值近似的跨 `G` 复用。
- 最大风险：任意 `G` 无压缩，或成熟多查询系统已覆盖。

### 组合 R3：决策诱导互补的结构化精确归因

- 通俗例子：企业数和就业数同时达到标准才改变选址，单项变化无效。
- 一句话问题：真实决策损失产生的互补，是否有关系来源可利用的专门精确结构？
- 理论问题：决策模型限制的交互阶数；与 JOIN/DISTINCT 交互的组合；成熟分解的覆盖边界。
- 玩家/价值：物理事实；决策收益或损失改善定义 `G`，收入 `R` 外生。
- 最强竞争：Abbas–Hazen、Data Shapley、MC-nets、model counting、aggregate-CQ Shapley。
- 未决核心：任务诱导结构能否比任意非线性 `G` 更紧凑。
- 最大风险：被标准 Boolean/局部交互分解完整覆盖。

### 组合 R4：合法玩家边界与可计算 quotient game

- 通俗例子：一个所有者跨表贡献多条记录，部分记录必须共同交付，公共维表由平台提供。
- 一句话问题：业务上合法的打包何时保持支付语义，并改变来源表示复杂度？
- 理论问题：record-sum 与 owner-game 一致条件；合法 quotient；宽度/依赖度变化。
- 最强竞争：FGSV、Owen、2D-Shapley、bounded-dependency games。
- 未决核心：真实供给/撤回规则与数据库来源结构的结合。
- 最大风险：为加速任意打包，或只得到显然的玩家数减少。
- 优先级：中，补 Owen 后再决定。

### 组合 R5：精确动态完整报表贡献

- 通俗例子：季度报表只修订少数记录，但 DISTINCT/比例使许多旧记录边际变化。
- 一句话问题：哪些更新事件可安全局部维护精确 Shapley？
- 理论问题：新增/删除/属性修订的对齐；全联盟边际不变条件；来源维护与归因维护的差距。
- 最强竞争：Xia 2025、Yang 2026、F-IVM、LExaShap/model counting。
- 最大风险：只是把成熟动态 Shapley 换成 SQL utility。
- 优先级：中低。

## 5. 当前建议

下一轮优先 R1、R2、R3；R4 等 Owen 和真实玩家边界证据；R5 暂缓。E1 作为最终删除检验保留，不预设为统一创新。
