# 模型与概念卡

| 层 | 原文对象 | IDEA-03 对应 |
|---|---|---|
| 来源 | 消费者产生 `s_i`，接受转移 `f_i` | 物理事实提供者/所有者 |
| 中介 | 收集、设计并传输 `I` | 数据库与完整报表生产者 |
| 买方 | 企业按信息选择价格/数量/行动 | 统计产品买方 |
| 信息设计 | 完整、噪声化、个性化信号 | 报表内容与精度 |
| 收益 | 消费者补偿、企业利润、中介利润、福利 | 不可统一叫“数据价值” |
| 交易时点 | ex ante structure / ex post realization | 订阅/一次性报表/按查询 |
