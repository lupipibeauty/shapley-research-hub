# 模型与符号卡

| 符号 | 含义 | IDEA-03 暂定映射 |
|---|---|---|
| `Ω` | payoff-relevant 状态 | 地区需求、医疗短缺或灾害真实状态 |
| `X` | 共同随机性/扩展状态 | 数据生成、抽样和来源相关性 |
| `π` | 扩展空间上的信号分区 | 一种来源/报表产品（需概率嵌入） |
| `π∨π̂` | 共同观察两个信号 | 买方内部数据加外购报表 |
| `D=(A,u)` | 行动集与状态效用 | 选址/资源配置决策 |
| `B` | Blackwell dominance | 对所有决策问题的孤立排序 |
| strong `B` | 对任意额外信号仍保持排序 | 上下文稳健的来源排序 |
| `O` | reveal-or-refine | strong ordering 的结构证书 |

必要区分：数据记录不是信号 realization；联盟不是信号 join，除非构造了相容的生成模型。
