# 证据缺口与下一轮阅读

## 原文缺口

1. Owen 1977 正文、定义、公理、定理和证明仍未获得；R4 只能继续开放。
2. Bounded dependency 的 arXiv 长版/补充证明未与会议版逐页对照。
3. Markets for Information 中引用的具体定理若进入论文，必须回读 Bergemann & Bonatti 2018、Admati & Pfleiderer 等原始论文。
4. 五篇均未完成作者代码核验；其中三篇本身不是实证/软件论文。

## 理论缺口

1. 确定性 SQL 报表到随机信号模型的合法嵌入。
2. SQL provenance 图到语义 dependency graph 的充分、必要和可认证条件。
3. SQL+G 到紧凑 MC-net 的表示规模界。
4. owner 权利结构是否真是不交先验联盟。
5. 多买方真实任务族是否共享一个可复用精确表示。

## 业务缺口

- 商业选址缺少统一公开决策规则与单个企业的“报表—行动”连接。
- HPSA/CDRZ 有规则与公开指定，但不等于存在报表交易或固定收入池。
- 三个场景都需要明确买方、交付物、价格/预算、行动与结果时间窗。

## 不触发实验的下一步

先补合法原文、规则版本和任务数据字典；再从一个任务构造最小状态—行动—损失模型并做数学可识别性审计。通过后才设计 Shapley 实验。
