# 扩展研究问题清单

这些方向是待验证的研究问题，不是已成立创新点，不设“关闭”标签，也不以单篇定理作否定判断。

## 保留并细化 R1–R5

### R1：表示冗余不变性与真实互补

- R1.1：同一报表的 SQL/来源表示改变但联盟输出不变时，Shapley 不变的最小语义条件是什么？
- R1.2：冻结任务等价是否能扩展为某一真实决策域内的信号等价？
- R1.3：provenance overlap、坐标 overlap、MC-net rule graph 与 semantic dependency graph 的蕴含关系是什么？
- R1.4：买方已有内部信号后，来源冗余/互补及记录贡献排序何时翻转？

### R2：精确多任务报表归因的离线—在线复用

- R2.1：同一 `Q`、多个任务 `G_b` 能共享哪些结构：lineage、状态空间、规则支持、依赖候选图或局部边际？
- R2.2：共享预处理后，怎样保证每个 `G_b` 仍是同目标精确 Shapley，而非近似或改换游戏？
- R2.3：真实买方任务族的差异是否足以使共享结构失效？

### R3：决策诱导互补的结构化精确归因

- R3.1：由行动损失定义的 `G` 在哪些 SQL 查询类上可编译成多项式大小 MC-net？
- R3.2：哪些决策互补会导致语义 dependency degree 上升，哪些只是句法来源重叠？
- R3.3：`T_compile+T_certify+T_solve` 的主导参数分别是什么？

### R4：合法玩家边界与可计算 quotient game

- R4.1：记录后汇总、owner-as-player 与 Owen 型先验联盟分配何时一致？
- R4.2：重叠所有权、共同退出权或公共维表如何破坏不交分区？
- R4.3：两层结算能否同时保证 union 间效率、union 内效率及物理记录可追溯性？

### R5：精确动态完整报表贡献

- R5.1：事实新增/删除后哪些 MC-net 规则与语义依赖邻域必须更新？
- R5.2：多任务共享结构能否摊销动态维护，还是某些 G 会导致全局重编译？

## 新增跨方向组合

### R6：任务域稳健的信息贡献（价值理论 + 合作博弈）

定义一类真实行动/损失函数 `𝒟`，研究来源 A 对 B 的优势是否在任意背景信息下成立，并把该信息价值诱导为合作博弈。验证条件：公开规则只是起点，还要有状态模型、行动和结果。

### R7：SQL-to-game 可认证编译（精确计算）

研究 `SQL/provenance → MC-net/电路/其他精确表示` 的语义证书和表示规模边界。重点是编译而非重复 MC-net 的逐规则 Shapley 公式。可与 R1、R2、R3 组合。

### R8：语义依赖的静态上界与可发现性（合作博弈 + 数据库理论）

从查询结构生成不漏边的依赖候选图，再利用 DISTINCT、聚合和 `G` 的代数性质认证删边。目标是避免 Theorem 13 的纯黑箱下界，同时说明静态候选何时过宽。

### R9：两层所有权结算（合作博弈 + 玩家制度）

在外生固定收入池下，比较 owner union 间和 owner 内两层分配；明确它与 FGSV、Owen 和 owner-as-player 的差别。是否有现实意义取决于合同中的控制和退出权。

### R10：来源—中介—买方三账本（价值理论 + 业务证据）

把买方决策价值、成交收入、中介加工价值/成本和来源贡献分开。Shapley 只对冻结的一个池归因；其他账本通过合同或机制连接。该方向需要真实交易证据，不由理论文章单独成立。

### R11：公共决策规则驱动的多 G 基准（真实任务 + 精确计算）

用 HPSA、灾害韧性等公开规则构造可审计任务族，测试多输出/多 G 共享计算。公开规则能冻结 `G`，但不能证明商业成交价值；应与商业选址中“规则缺失”形成对照。

### R12：信息背景敏感的贡献区间（价值理论）

若买方已有信号不可观测，只知道一个允许集合，研究记录贡献在该集合上的上下界或稳健排序。它不是标准单游戏 Shapley，需要先定义规范目标，再审查稳健信息设计和不完全信息合作博弈文献。
