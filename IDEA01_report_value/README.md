# IDEA01：报表／买方价值定义

## 1. 研究问题

Shapley 价值函数应针对单条记录、买方、局部结果还是整份层次报表定义？不同价值函数是否会改变玩家贡献的解释对象和可比性？

## 2. 探索过的方向

- 旧 D1 精确一致性实验比较了不同精确实现，但其核心是算法一致性，不是独立的买方／整报表价值问题。
- 层次报表与结构实验提供了价值函数和玩家边界的材料，但没有形成专门的 IDEA01 因果对照。
- 审计中曾把该方向与玩家粒度、报表层次混在一起，第二轮后改为候选账本。

## 3. 实验设计与目的

候选设计是固定同一数据库和查询，仅改变价值函数视角，同时保持玩家集合、联盟枚举和精确算法不变，比较贡献排序、效率性和解释差异。该设计尚未获批运行。

## 4. 实际完成度

**仅有相关历史材料，没有可独立归属 IDEA01 的完整实验。** 不能把 M1、P2 或 GNN 结果直接作为 IDEA01 的完成证据。

## 5. 停止／阻塞原因

- 研究动机尚未收敛为可检验问题。
- 玩家绑定规则和报表价值函数未同时冻结。
- 现有报告缺少专门的逐配置结果和原始计时。
