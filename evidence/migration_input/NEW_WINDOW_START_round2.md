# 新窗口恢复研究：两个读法

## 阅读整个研究状态
“请只读读取本研究仓库的 `RESEARCH_STATUS.md`、`research/IDEAS.md`、`research/ROUND2_FACTS.md` 及历史索引说明。列出所有 Idea 当前状态、已核验证据、被否定方向与阻塞项。不要启动新实验。”

## 恢复指定 Idea
“请读取本仓库 `RESEARCH_STATUS.md` 和 `research/IDEAS.md` 的 IDEA-04 部分，再检查与该 Idea 有关的 Issue、PR、run manifest 和仓库证据记录。说明实验目的、玩家/价值定义、已执行结果、失败经验、与别的 Idea 共享的基准、下一步门禁。未经批准不运行代码或改动状态。”

## 访问边界
浏览器中的新 ChatGPT 对话必须能访问已连接/公开的 GitHub 仓库才可直接读取；本地 Codex 可以在已打开的工作目录读取。只有写在本地 `<SOURCE_PARENT>\...` 的日志并不能被云端任意窗口自动看到。远端需要保存足够的状态摘要、证据索引和可恢复存储位置。
