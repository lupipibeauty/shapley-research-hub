# Experiment and Research-Framework Report

This report consolidates all formal experiments completed for the course paper:

- data generation and exact Shapley labels;
- SQL audits;
- additive and Feature-MLP baselines;
- RPV-GNN and graph/anchor ablations;
- cached Monte Carlo at three budgets;
- regression control-variate MSR;
- value-conditioned safe routing;
- graph-edge perturbation;
- D1-P/P3 external zero-shot adaptation;
- dummy-player structural-zero control;
- seed-uncertainty diagnostics;
- parameter counts and DuckDB end-to-end cost.

It also defines the research scene, research object, formal contribution target,
RPV-GNN architecture, and the theoretical relationships used by the design.

The report distinguishes passed, negative, descriptive, and incomplete evidence.
It does not claim cross-database generalization or dominance over high-budget MC.
