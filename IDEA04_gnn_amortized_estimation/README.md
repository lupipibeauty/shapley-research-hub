# IDEA04：GNN 摊销贡献估算

## 1. 研究问题

在同一来源模式下，图神经网络能否从图结构和价值条件学习玩家贡献，以一次训练换取大量重复游戏的低成本近似？

## 2. 实验设计路线

- **数据与监督**：TPC-H SF0.1 派生 1000 个游戏，使用精确联盟值作为监督与测试依据；另有 SF1 规模外推游戏。
- **主模型**：来源—价值异构图、关系感知消息传递、图级池化、玩家贡献头、解析锚定／残差分解、单纯形约束和安全路由。
- **消融**：移除图边、移除解析锚点，检查来源结构和解析先验的作用。
- **结构稳健性**：图结构扰动、哑玩家控制、种子不确定性。
- **泛化与成本**：价值条件组合分布外、规模外推、外部零样本、MC 回归基线和 DuckDB 端到端成本。

## 3. 实际完成度与结论

课程实验已覆盖分布内、组合分布外、SF1 外推、消融、扰动、哑玩家、不确定性、控制变量基线和端到端成本。结果支持来源关系对组合分布外估计有实质作用，安全路由在部分场景接近 MC-256 且成本更低；MC-1024 仍更准确。

方法应定位为**同一来源模式下重复贡献估算的摊销近似**，不是精确算法，也不是通用跨数据库迁移模型。

## 4. 已确认的结构限制

玩家—物理事实映射嵌入冻结 JSONL 的 `players`、`relation_key`、`links` 和 `metadata`；当前代码只构造玩家到 witness、coordinate、factor、report 的正向边，没有发现反向边或自动双向化。消息沿 source 到 target 聚合，玩家局部隐藏状态不能经图层接收下游 witness 信息；图级池化仍向贡献头提供全图 context。

## 5. 停止／边界原因

外部游戏零样本适配没有形成稳定优势；MC-1024 仍有准确性优势；训练 lineage 尚缺输入数据哈希、生成命令快照和代码提交记录；反向边对照尚未作为独立受控实验运行。

## 6. 下一步边界

若继续，只能以冻结正向边基线为对照，单独设计反向／双向边可达性实验并补齐数据 manifest，不能改写现有结果为“已学习完整下游来源关系”。
