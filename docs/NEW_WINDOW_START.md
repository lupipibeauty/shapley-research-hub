# 新窗口科研管理入口

本仓库是 Shapley 数据库收益分配研究的档案与工作流入口，不是原始实验工作区。

开始时依次阅读：

1. `README.md`
2. `RESEARCH_STATUS.md`
3. `research_state.yaml`
4. `research/IDEAS.md`
5. `research/DECISIONS.md`
6. `research/EXPERIMENT_INDEX_CURRENT.csv`

处理任何历史结论前，先区分证据等级和研究状态，再通过 `evidence/round2/` 与索引中列出的原始路径核验。不要把本地 Git 基线当成旧实验的提交历史。

未经用户明确批准，不创建 GitHub 远程／Issue／分支，不迁移原始代码或数据，不修改旧工作区。
