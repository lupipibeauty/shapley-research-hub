# 02 受控来源夹具

## 已执行设计

E1 冻结 F2 ENTITY_LINK、4 个业务场所、2 个企业、6 个实体—城市链接，总玩家数 16。三个配对分别使用预先固定的就业数 `(8,12,15,5)`、`(9,11,14,6)`、`(7,13,16,4)`；每对的 concentrated/dispersed 保持 E/B/H/R 行数、玩家编号、12 个 JOIN 见证和总变量出现数不变。

concentrated 将每个企业的三个链接放在同一城市；dispersed 将其中一个链接放到同省另一城市。三个配对共执行 390 个确定性 SQL/Python 掩码核验，全部一致。

## 实际结构指标

六个游戏均为：12 个最小见证、48 次变量出现、30 对重叠证明、primal graph 42 条边、2 个连通分量、min-fill treewidth 上界 5、GC 六个有限阈值分量、392 个 Harsanyi 项、最高阶 16、108 条原始 DNF 子句与 63 条唯一子句。

变化只出现在六维统计状态：concentrated 为 16，dispersed 为 49。原因是城市分散增加了完整报表可达状态，但省级 GC 把同省城市作 OR 后，布尔激活条件仍相同。因此“完整报表状态数增加”没有自动转化为“当前价值来源表示变大”。

## 未完成的控制

这个 E1 不是跨省共同来源实验。同一企业仍只链接 PA 或 PB，没有同一物理企业玩家同时出现在两个省的来源式中。它也没有独立改变替代证明数：两种模式每个企业始终有 3 条链接。故本轮只完成了“同省城市分散”控制，没有完成下列三个因素的正交分离：

1. 单一 DISTINCT 对象的替代证明数；
2. 跨指标物理玩家复用；
3. 跨省证明重叠方式。

这不是静默缺口：状态记为 `PARTIAL_CONTROL`。下一夹具必须允许同一 E 或其他原生玩家跨 PA/PB，同时保持每省证明数、总见证数和阈值可达状态固定；否则不能用 E1 推断跨地区共享的成本效应。
