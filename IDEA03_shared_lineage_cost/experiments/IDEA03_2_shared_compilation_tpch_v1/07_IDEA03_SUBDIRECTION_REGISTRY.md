# 07 IDEA-03-2 子方向登记

## 2A 联合价值退化与有效性

- 明确问题：阈值、比例与跨地区门控何时产生真实上下文交互？
- 已有证据：历史 G1 在阈值 1 下解析退化；k=2 的 GR/GL/GC 不等价，GC 有 36 个跨地区非零二阶差分。
- 未证实猜想：存在既非退化又具有多个非零 GC 状态的最小完整报表族，并能给出交互阶数边界。
- 最强竞争解释：现象只是 unanimity gate，不是新结构。
- 下一实验：固定 k=2，增加每省第三个可替代企业/见证，使 GC 至少有多个中间非零状态。
- 推翻条件：所有实际可解释阈值在来源语义下都退化，或只产生无应用意义的 unanimity game。
- 状态：`VERIFIED_AUDIT_RESULT / CANDIDATE_NOT_INNOVATION`。

## 2B 固定状态下的来源表示增长

- 明确问题：状态数固定时，唯一证明、重叠和图宽如何控制表示规模？
- 已有证据：上一阶段同为 16 状态却有 8–72 个 Harsanyi 项；本轮 16/49 状态又可有完全相同的 GC 表示。
- 未证实猜想：表示规模可由唯一阈值子表达式数与有序图宽联合界定，而非由玩家数或状态数单独界定。
- 最强竞争算法：d-tree/d-DNNF/BDD/VE 的既有图宽参数化结果。
- 下一实验：固定价值状态和见证数，正交改变跨省共享变量与 primal treewidth。
- 推翻条件：成熟编译宽度指标已完整预测并覆盖该现象，数据库报表结构不提供额外可利用条件。
- 状态：`SUPPORTED_CANDIDATE / CONTROL_INCOMPLETE`。

## 2C 共享编译与全部玩家精确 Shapley

- 明确问题：多输出阈值事件能否共享来源电路并一次恢复全部玩家 Shapley？
- 已有证据：ROADD cardinality DP 精确；作者 LExaShap 完整分量缓存精确；warm 重用显著降低 solve 时间。
- 未证实猜想：从 SQL provenance 直接构造的多输出共享电路可降低冷端到端成本。
- 最强竞争算法：官方 LExaShap d-tree、知识编译的 all-marginals/梯度方法、合并 Harsanyi。
- 下一实验：不经真值表，直接从共享来源 DAG 构造多输出 d-DNNF/SDD 或 VE，并报告冷编译。
- 推翻条件：作者电路加完整分量缓存已消除全部实际重复，部分子图共享不降低冷成本。
- 状态：`EXACTNESS_VERIFIED / SPEED_ADVANTAGE_NOT_SHOWN`。

## 2D 共享增加但表示变小的条件

- 明确问题：何时公共前缀因式分解超过高连接度带来的宽度代价？
- 已有证据：上一阶段 concentrated 的 Harsanyi 项可少于 balanced；本轮同省分散控制则表示完全相同。
- 未证实猜想：若共享变量形成可提取的模块且不跨越分解割集，集中会减小表示；否则会增宽。
- 最强竞争理论：知识编译中的 vtree/变量顺序与 treewidth/pathwidth 结果。
- 下一实验：固定证明数，构造“共享在模块内”与“共享跨割集”两类配对。
- 推翻条件：所有差异均由不公平的证明数或变量顺序造成。
- 状态：`OPEN_WITH_MIXED_EVIDENCE`。

## 2E 负 Shapley 与固定收入

- 明确问题：比例型报表中降低产品评分但仍为必要来源的事实，应如何映射到固定收入？
- 已有证据：E0 GR 有 384 个负边际和 6 个负 Shapley；TPC-H LOCAL/CROSS 也出现负玩家。
- 未证实猜想：结构零、预算平衡、非负支付无法在保留标准 Shapley 的同时全部满足，需要独立分配层。
- 最强竞争方案：标准 Shapley、截断/投影、受约束分摊与安全路由。
- 下一实验：先形式化公理冲突，再比较支付层；不得修改底层 Shapley 后仍称精确 Shapley。
- 推翻条件：业务合同允许负支付，或价值函数改为有理论依据的单调效用后负值消失。
- 状态：`VERIFIED_PHENOMENON / SEPARATE_ALLOCATION_LAYER`。

优先级：先 2A 修正价值有效性，再以 2B 的正交夹具检验 2C；2D 作为理论解释，2E 独立于算法性能。
