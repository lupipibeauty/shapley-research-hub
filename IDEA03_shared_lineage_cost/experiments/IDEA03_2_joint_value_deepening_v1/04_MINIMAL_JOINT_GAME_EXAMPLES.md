# 04 可手工核对的联合价值例子

## 满联盟

F0 有 10 个玩家：2 条 E、4 条 B、4 条 H。甲省两场所就业分别为制造业 8、服务业 12；乙省为制造业 15、服务业 5。因此

\[
(C_A,M_A,W_A,C_B,M_B,W_B)=(1,8,20,1,15,20),
\]

\[
G_0=63/80,\qquad G_1=G_2=23/40.
\]

满联盟数值相同不代表游戏相同；三者在中间联盟上的边际不同，完整记录 Shapley 见 `raw/record_shapley.csv`。

## 跨省上下文边际

考察服务业就业事实 `H:S2`，它直接只改变甲省 (W_A)。

1. 联盟 (S_1=\{E1,B:S2\})：加入 `H:S2` 后甲省覆盖成立但 (r_A=0)，乙省未覆盖，故 (G_2) 从 0 到 0，边际为 0。
2. 联盟 (S_2=S_1\cup\{E2,B:S3,H:S3\})：乙省制造业场所已激活，(T_B=1,r_B=1)。加入 `H:S2` 后 (T_A=1,r_A=0)，故 (G_2) 从 0 到 (1/2)，边际为 (1/2)。

这满足“事实只直接改变一省统计，但 G2 边际依赖另一省状态”。机器可核记录为 `raw/minimal_context_marginals.csv`。

## 完整记录分配中的负值

F0-G2 中：

- `H:S2 = -131/4800`，金额映射为约 -27.292；
- `H:S4 = -13/2400`，金额映射为约 -5.417；
- 制造业 `H:S1 = 123/1600`、`H:S3 = 79/800` 为正。

负值来自服务业事实提高分母并降低制造业占比，不是算法误差。所有玩家分配精确求和到满联盟价值；官方 LExaShap 与 Harsanyi 对 oracle 的最大误差均低于 (6\times10^{-17})。
