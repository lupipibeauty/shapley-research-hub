# 02 G0/G1/G2 的数学分解

## 游戏与零分母规则

固定物理事实玩家集 (N)，联盟报表 (Y(S)=Q(D_S))，且

\[
v_j(S)=G_j(Y(S))-G_j(Y(\varnothing)).
\]

SQL 对零分母保留 `NULL`；评分层冻结为 (r_p=0)（当 (W_p=0)），否则 (r_p=M_p/W_p)。本轮 (k_A=k_B=1)。金额 (1000\phi_i) 只是事后映射，不改变游戏。

## 可分解性

由 Shapley 线性性，

\[
\phi_i(G_0)=\tfrac14\{\phi_i(T_A)+\phi_i(T_B)+\phi_i(r_A)+\phi_i(r_B)\}.
\]

这只说明可分别计算四个分量，不说明比例是线性的。对 (G_1)，同省事实的边际为

\[
\Delta_i(T_pr_p)=T_p(S\cup\{i\})r_p(S\cup\{i\})-T_p(S)r_p(S),
\]

门槛变化和比例变化必须在同一省联合表示。对只影响甲省的事实，(G_2) 的边际含有

\[
\Delta_iG_2(S)=\frac{T_B(S)}2\left[T_A(S\cup i)(r_A(S\cup i)+r_B(S))-T_A(S)(r_A(S)+r_B(S))\right].
\]

因此乙省覆盖状态可以把同一甲省事实的边际从 0 改为非零。

## 比值的有限阈值展开

对冻结整数域，令 (h(m,w)=m/w)（(w>0)）且 (h(m,0)=0)。在各自可达的有序 (M,W) 水平上做二维有限差分：

\[
r(M,W)=\sum_{m>0,w>0}\Delta_m\Delta_w h(m,w)
\mathbf 1\{M\ge m\}\mathbf 1\{W\ge w\}.
\]

每个阈值事件可由场所激活 provenance 的最小 DNF 精确表达。于是 G0/G1/G2 都可转换为带实数（本实现用 `Fraction`）系数的 Boolean DNF 线性组合，再分别交给 LExaShap 或转成 Harsanyi 多项式。该结果是有限冻结域上的精确转换，不是对任意连续比值函数的常数规模表示。

## 必要状态与负贡献

- 要重建 (T_A,T_B,r_A,r_B)，一般至少保留 ((C_A,M_A,W_A,C_B,M_B,W_B))。只保存 (r_p) 会丢失零分母、门槛和不同 `(M,W)` 的后续边际。
- 服务业就业激活会增加 (W) 而不增加 (M)，所以比例下降，边际与 Shapley 都可能为负。
- 但负性不是必然：F0 的 `H:S2` 在 G0 中 Shapley 为 (1/300>0)，因为其门槛正贡献抵消比例下降；在 G1、G2 中分别为 (-3/50) 与 (-131/4800)。

## 已核验规模

canonical run 中 F0/F1/F2 的六维联合统计可达状态都为 16；Boolean 分量数 G0=8、G1=6、G2=6。真正变化的是每个分量的 DNF/变量共享和展开后的 Harsanyi 项数，而不是分量个数本身。
