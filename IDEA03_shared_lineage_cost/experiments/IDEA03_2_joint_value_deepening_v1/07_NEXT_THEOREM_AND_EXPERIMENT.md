# 07 下一项理论命题与判别实验

## 候选命题（尚未证明）

设每个统计对象激活事件由单调 DNF 表示；G 依赖 (d) 个整数聚合，每个聚合具有有限阈值层集合 (L_j)。若 G 在这些离散网格上的有限差分支持为 (Gamma)，则 G 可表示为至多

\[
|\Gamma|
\]

个阈值事件乘积的加权和。实际编译规模进一步由这些事件的共享 provenance 子电路决定，而不是只由玩家数决定。需要证明的不是这个形式展开本身，而是：在给定 vtree/变量序下，共享编译规模能否由 provenance incidence width、(|\Gamma|) 与 G 的交互宽度共同上界。

## 下一项最小实验

1. 保持 F2 的 E/B/H/R2、玩家数和满联盟报表不变，只改变“同一 R2 被多少场所/指标共享”。
2. 构造相同的阈值层数与相同 G2 有限差分支持，避免把值域变化混入来源变化。
3. 实现一个真正的共享阈值电路：各省的 `M>=m`、`W>=w`、`C>=k` 只编译一次，G0/G1/G2 复用节点。
4. 为 ROADD/SDD/d-DNNF 中至少一个表示加入按联盟大小计数与全变量梯度；先在 N≤16 与当前 oracle 核验。
5. 比较“逐分量官方 LExaShap”与“共享编译”的节点数、转换时间、编译时间和全玩家求解时间。

停止条件：若共享编译节点数与时间没有稳定减少，或成熟 d-tree 已自动完成等价共享，则保存否定结果，不扩到 N>32。只有第三个非枚举精确求解器通过同目标正确性后，才进入 N=20–32。
