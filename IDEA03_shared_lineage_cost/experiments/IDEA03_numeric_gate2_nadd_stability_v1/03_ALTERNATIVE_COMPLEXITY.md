# 替代路径复杂度

令 child 数为 `r`，第 `i` 个多项式次数为 `d_i`，总次数 `n=Σd_i`。朴素卷积两个次数 `a,b` 的成本为 `Θ((a+1)(b+1))`。

## 当前反卷积

- forward 总乘积：顺序卷积最坏 `O(n²)`；
- backward：每个 child 做一次次数 `n` 除以 `d_i` 的长除法，合计 `O(Σ n d_i)=O(n²)`；
- 工作空间：总乘积加一个当前商，`O(n)`，不计节点已有梯度；
- 风险：多项式除法是逆问题，可发生消去和误差放大。

## Prefix/suffix

- 构造全部 prefix 与 suffix：朴素顺序卷积合计 `O(n²)`；
- 对每个 child 合并 `L_i*R_i`：一般上界可到 `O(rn²)`，均匀固定小次数 child 时更接近输出规模 `Ω(rn)`；
- 存储全部 prefix/suffix：最坏 `O(rn)` cells；
- 优点：只含正向卷积，无多项式除法。

## Product tree

- 平衡向上构造：朴素卷积 `O(n²)`；
- 向下传播 complement × sibling：逐层上界 `O(n²)`，总计保守 `O(n² log r)`；
- 树产品及传播中间量：`O(n log r)` 的保守 cell 上界，实际取决于是否及时释放；
- 保留平衡结构，有利于限制单条顺序链和复用 sibling products。

三者在本任务的作者全局界 `O(|T|n²)` 语境下不改变最终 Shapley 定义。是否具有“可忽略成本”不能只由大 O 判断，需用冻结操作计数和存储单元验证。
