# 本地 wrapper 审计

## 实际公式

作者 `Value.backward()` 在根节点设置长度 `N+1` 的梯度：

\[
g_0=0,\qquad g_{s+1}=s!(N-s-1)!,\quad s=0,\ldots,N-1.
\]

作者的 `prob` 向量按联盟大小保存经过 `2^{-N}` 归一化的赋值计数。官方 backward 返回每个叶变量的梯度向量，而不是最终标量 Shapley。本地适配层计算

\[
\widehat\phi_i=
\langle \mathrm{grad}_i,\mathrm{prob}_i\rangle
\frac{2^N}{N!}.
\]

`2^N/N!` 只在 wrapper 中乘一次；作者 backward 没有再次包含这项全局归一化。没有重复乘阶乘、二项式系数或 `2^N`。

## 小实例核验

`m=2,k=5,N=10` 时，作者叶向量点积为 `354.375`，scale 为 `0.0002821869488536155`，结果为 `0.09999999999999999`，与解析值 `1/10` 一致。`N=5` 至 `N=55` 的全部解析实例也在 `1e-10` 门内通过。

## 标签与顺序

解析扫描显式构造有序标签列表，并以该列表创建唯一 `Value` 对象。`label_mapping_audit.csv` 的 730 行全部满足：作者标签、最终标签、位置和对象 identity 一一一致；零 mismatch。DNF 的集合迭代顺序不会改变最终按显式标签字典提取的叶对象。

## N=60 的层次定位

`N=60` 时，作者 raw backward 已将单个叶的点积算成 `-1.7806528845188158e71`；正确的 100 位同递推点积为约 `1.2028843073144134e62`。wrapper 只是把前者乘以正的 `1.3855585749453365e-64`，因此错误在标量转换前已经存在。

结论：没有发现本地 wrapper、玩家标签或索引错误。
