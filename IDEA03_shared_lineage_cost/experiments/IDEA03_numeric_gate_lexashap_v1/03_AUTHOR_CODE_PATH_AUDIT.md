# 作者代码路径审计

## 调用路径

1. 叶变量：`Value(0.5, {label})`；
2. 五变量子句：`Value.N_mul` 进行卷积；
3. 互不相交子句：`Value.N_add` 形成根 OR；
4. `Value.backward()` 注入阶乘 Shapley 权重并反向传播；
5. `N_add._backward()` 调用 `scipy.signal.deconvolve`，从全部不满足分布除去当前子句的不满足分布；
6. wrapper 将叶梯度向量归一化为标量。

## 逻辑边界检查

没有发现 `N`/`N-1`、向量长度、padding、slice、range endpoint 或标签 branch 的离散边界 bug。`N=60` 处源码没有特殊分支；失败边界与代码分支无关。

作者 helper 的反卷积采用浮点多项式长除法。对冻结解析族，预期商可独立写成当前五变量子句不满足分布的 `m-1` 次卷积，因此无需联盟枚举即可直接核验。

## 首个错误位置

- `N=55`：作者商与独立卷积商逐项一致；
- `N=60`：商在索引 24 首次偏离，最大绝对误差 `4.0851436816646824e-08`，L1 误差 `1.354294085487151e-07`；
- 手工复刻相同浮点长除法与 SciPy 商完全一致，排除 SciPy 接口误用；
- 最大有限减法 cancellation ratio 从 `201`（N=55）升至 `5639.1333`（N=60）；
- 随后阶乘根梯度最大值约 `1.3868e80`，把商误差放大为子句梯度约 `5.6981e72` 的错误，而正确量级约 `5.5178e65`。

因此，异常首先出现在 `N_add._backward()` 的浮点反卷积，不是电路构造、叶乘法、标签映射或最终归一化。
