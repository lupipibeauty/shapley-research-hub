# 内部数值轨迹

最后正确点 `N=55` 与首个失败点 `N=60` 的对照：

| 指标 | N=55 | N=60 |
|---|---:|---:|
| 商最大绝对误差 | 0 | `4.0851e-8` |
| 商 L1 误差 | 0 | `1.3543e-7` |
| 首个错误商索引 | 无 | 24 |
| 最大有限减法 cancellation ratio | 201 | 5639.13 |
| 根阶乘梯度最大值 | `2.3084e71` | `1.3868e80` |
| 子句梯度最大误差 | 0 | `5.6981e72` |

诊断链为：浮点长除法的重复减法产生商误差，极大的阶乘梯度再将其放大。这里可以标记 `CANCELLATION_SUSPECTED` 与 `GRADIENT_AMPLIFICATION_CONFIRMED`。它说明当前实现的有限精度条件不良，不等价于所有 Shapley 算法都存在同样问题。

完整逐点数据见 `results/numeric_trace.csv`。
